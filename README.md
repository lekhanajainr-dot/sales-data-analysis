# 📊 Sales Data Analysis Using Python

A beginner-friendly end-to-end data analytics project using Python to analyze sales, products, regions, monthly trends and profitability.

## 🎯 Objective
The goal is to turn raw sales data into useful business insights by:
- Cleaning and preparing the data
- Performing exploratory data analysis (EDA)
- Measuring sales and profit
- Comparing product and regional performance
- Identifying monthly trends
- Creating visualizations
- Summarizing business insights

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Analysis Performed
1. Dataset overview and data types
2. Missing-value and duplicate checks
3. Data cleaning
4. Total sales, profit, orders and units sold
5. Product-level sales analysis
6. Regional sales analysis
7. Monthly sales trend
8. Product profitability analysis
9. Correlation analysis
10. Business insights

## 📈 Key Outputs
The notebook generates charts for:
- Sales by product
- Sales by region
- Monthly sales trend
- Profit by product
- Correlation between numerical variables

## ▶️ How to Run
1. Install Python 3.
2. Clone/download this repository.
3. Open the project in VS Code or Jupyter.
4. Install dependencies:
```bash
pip install -r requirements.txt
```
5. Open `notebooks/sales_analysis.ipynb`.
6. Run the cells from top to bottom.
